## 保存内容与查看方式

- [preview.html](preview.html)：无需构建，直接用浏览器打开。复用原始 `desktopFrame.css`、历史 logo 和图标，展示外壳与浅/深内容底色。中间的说明内容是归档预览占位，窗口按钮仅用于展示。
- [主应用外壳](source/frontend/src/shell/DesktopFrame.tsx)与[完整样式](source/frontend/src/shell/desktopFrame.css)：保留导航、拖拽区、窗口按钮、身份胶囊插槽和八向缩放热区。
- [首帧骨架](source/frontend/index.html)：与外壳配套的启动占位，防止进入主应用时闪白或形状跳变。
- [桌面启动页](source/desktop/ui/index.html)：保留同一视觉语言的完整历史启动器，以及它依赖的 logo、图标与图标许可证。其业务脚本依赖旧版桌面运行时；不作为独立可运行应用。
- [原生窗口实现](source/desktop/src/main.rs)、Tauri 配置与 Cargo 依赖：保留透明窗口、系统装饰、阴影、页面切换等行为的历史依据。

浏览器预览用背景渐变模拟桌面，以便看清半透明窗缘；它不代表系统桌面模糊效果。历史原生实现的 `.effects(EffectsBuilder::new().build())` 列表为空，**实际没有启用系统 blur/acrylic**。原样归档，未来适配时再按平台处理。

`source/` 是设计与实现快照，不是独立工程；React 外壳仍引用当时应用内的品牌、主题状态等模块。需要完整历史工程时，可从上述完整提交恢复到单独目录。
