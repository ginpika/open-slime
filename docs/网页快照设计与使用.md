# 网页快照

使用 Playwright Java 1.58.0 控制隔离的 Chromium，Mozilla Readability 0.6.0 提取正文，jsoup 1.21.2 清洗 HTML。Spring 后端负责浏览器与 SQLite 正本，React 前端使用 Tailwind 类和现有主题令牌。无需搜索 API 或额外 Node 服务。

## 两个入口

- **会话**：Agent 调用 `web_browser` 搜索 Google、打开文章、阅读与筛选；`capture` 返回不可变的 `capture_id`、段落编号和证据文本。`save_web_snapshot` 接收质量判断、摘要以及引用正文段落的论点。会话输入工具栏的「浏览器」按钮可查看画面；预览为只读，刷新不会使 Agent 的元素引用失效。
- **网页快照页面**：输入 URL → 浏览器打开并提取正文 → 核查 → 可选按指令蒸馏 → 保存。未配置模型时仍可保存正文。人工入口有后退、滚动、元素点击、填写和按键控件。

地址栏与来源链接会解码中日文等 UTF-8 字符用于显示，访问仍使用规范化 URL。保留 `%2F`、`%26` 等分隔符编码，不进行二次解码；非法 UTF-8 和不可见方向控制符保留编码。

人工入口的浏览器画面支持鼠标滚轮和触控板横向/纵向滚动：按截图缩放比例映射鼠标位置与距离，转发给 Playwright，可滚动鼠标所指的嵌套区域。连续事件合并并串行发送，保留 Ctrl+滚轮的本地缩放操作；画面之外正常滚动页面。仍保留「向上/向下」按钮。会话中的 Agent 浏览器画面保持只读观察。

滚动状态放在浏览器标题栏内的固定宽高区域，滚轮和按钮滚动均不会在组件上方插入状态行，避免画面位置抖动。

「快照包含的媒体」独立选择图片（默认开启）、音频与视频（默认关闭）。切换后重新提取当前正文、更新预览并重置蒸馏草稿；保存和导出采用同一份预览内容。Agent 的 `web_browser.capture` 同样接受 `images`、`audio`、`video` 布尔参数。

Agent 应依据用户授权决定是否保存；网页文字始终是待分析资料，不能覆盖用户指令。工具定义归文档领域：内置会话自动获得工具，自定义 Agent 的额外写入工具按现有授权界面配置。

## 内容与检索

`web_snapshot` 保存 URL、作者、原发布时间、抓取时间、SHA-256、净化后的正文 HTML、生成摘要、保存理由、论点引用、生成来源、提取警告和向量状态。正文和模型论点分别保存；HTML 模板由程序生成，模型不直接输出可执行 HTML。

相同 URL 和正文哈希复用已有快照，内容变化保存新记录。正文中标题、段落、列表、表格、代码和引用保留，并分配 `p1` 等稳定锚点。每条模型论点必须引用实际存在的锚点；这只校验引用存在性，不保证语义支持，仍需核查原文。

Wiki 页面优先使用 `.mw-parser-output` 等正文容器，保留完整知识结构；普通文章仍使用 Readability。提取前移除站点导航、侧栏菜单、目录、编辑入口和页脚导航，回退也使用清理后的正文。信息框独立保护，不因侧栏位置或链接密度被丢弃；支持常见 infobox、portable-infobox，以及 Aigis/Fandom 的 unit-infobox（含官方名称、日文、罗马字、称号、作者与不同版本立绘）。字段转为表格或定义列表进入证据索引。折叠的知识内容展开。预览与导出使用相同的右侧信息框布局，窄屏改为整行。已保存的旧快照不会自动改写，需要重新提取。

Aigis 信息框的 Base/AW/AW2v1/AW2v2 与 Gallery 的 Versions 根据 `_toggler_show-*` 内容关联重建为快照自己的 Tab；也识别标准 MediaWiki `.tabber/.tabbertab`。收集页面 DOM 中已加载的全部版本，包括原站隐藏的内容，不执行或保留原站 JavaScript。清洗后生成独立的原生 radio/label 控件与 CSS，鼠标和方向键均可切换；保持 iframe 沙箱和禁用脚本。预览、保存后阅读与导出的离线 HTML 均支持切换，打印展开全部版本。每组控件独立，隐藏版本的正文同样进入证据索引，证据锚点可展开目标内容。需要点击后请求服务器才加载内容的其他 Tab，目前需先在浏览器中加载对应内容。

Gallery 的每项图片与说明转为网格图文，普通图片和 GIF 均保存；Fandom CDN 去掉缩略图尺寸段，优先请求 `format=original` 原图。不同版本不因当前隐藏而漏存。相同媒体 URL 在单次捕获中复用下载结果，避免 Gallery 与信息框中的同一立绘重复下载；原图不可取时尝试已加载的图片来源，无法保存的项目保留明确占位与警告。

正文证据发布为 `documents.source='snapshot'` 下的 `chunks`，立即进入关键词检索；已配置向量模型时在后台向量化，失败不丢正文，可重试。首页搜索命中后跳转本地快照。模型生成论点不会混入正文事实索引。图谱提取通过「审核图谱提取」连接现有文档分析流程。

详情支持改名、停用/启用检索、重试向量、删除及下载自包含 HTML。名称旁的「改名」展开内联表单，支持 Enter 保存和 Escape 取消，名称为 1～500 字符。`PATCH /api/web/snapshots/{id}/title` 同步快照、所属文档、分块的标题和关键词标题索引，导出 HTML 和图片清单使用当前名称；该操作更新名称元数据，保留已捕获的正文证据与派生记录。删除清理文档、分块、向量与由这些分块承载的图谱关系。数据库是正本，正文和分块在同一事务提交；导出文件随时从数据库生成。

详情页正文下方提供「图片资源」：显示图片位置数、去重后的独立图片数、GIF 数及导出图片大小；缩略图支持全部/GIF/静态图筛选、分批展开和单张下载。「下载全部图片 ZIP」提取已保存 HTML 中的全部内嵌 raster 图片，包括隐藏 Tab；按原始文件字节 SHA-256 合并重复图片，原样保存 PNG/JPEG/WebP/GIF。文件名依据图片说明生成并清理路径及非法字符；ZIP 的 `manifest.json` 记录快照来源、每张图片的格式、字节数、哈希及各次出现的说明、位置和版本。图片清单接口为 `GET /api/web/snapshots/{id}/images`，ZIP 为 `GET /api/web/snapshots/{id}/images.zip`。不访问原站，不修改快照；旧快照只要保存了内嵌图片也可导出。清单不会再次传输 Base64 图片；前端复用详情中已有图片作为缩略图，ZIP 在后端流式输出。

## 浏览器与资源

所有 Playwright 对象由一个专用线程操作，避免 Java SDK 的线程安全问题。浏览器会话按 Agent 与会话/任务隔离；人工操作按已登录用户隔离。最多 8 个浏览器会话，闲置 30 分钟清理；最多 32 个待保存捕获，30 分钟后过期。关闭浏览器不会立即删除已提取的正文。

网页预览显示受控浏览器截图，而非嵌入远程 iframe。离线正文放在无脚本、无网络权限的 iframe 中。网络路由检查初始导航、跳转和子资源，仅允许公开 HTTP/HTTPS 读取，阻止网站 POST 等写入、下载、服务工作线程及 WebSocket。验证页会返回阻塞提示，不自动处理验证码。

正文上限 12 万字符，页面单次模型蒸馏上限 6 万字符；工具可分页读取更长证据。勾选的媒体以内嵌 data URI 保存，离线预览与导出的 HTML 可直接显示或播放，音视频提供原生播放控件且不自动播放。Readability 提取时用占位符保留正文中的媒体位置，避免音视频被正文过滤器删除。

最多尝试 256 张 PNG/JPEG/WebP/GIF，Gallery、信息框、其他 GIF 按顺序优先；静态图每张最多 12 MB、GIF 最多 16 MB，唯一下载的图片合计最多 64 MB；4 项音频，每项最多 8 MB；2 项视频，每项最多 16 MB；唯一下载的媒体总量最多 80 MB。支持 WAV/MP3/MP4/Ogg/WebM/FLAC 音频与 MP4/WebM/Ogg 视频，具体解码能力取决于浏览器。正文内的视频封面遵循图片选项。媒体读取有逐资源超时和 60 秒总预算，流式读取限制实际字节数（包括未提供 Content-Length 的响应）；最多跟随 3 次跳转，逐次检查地址并按目标域匹配当前隔离会话的 cookies。捕获缓存总 HTML 上限为 1.28 亿字符，超限优先清理旧捕获；单份超过此限时明确拒绝，避免无界缓存。

GIF 不转码、不抽取静态帧，完整原始字节内嵌。优先读取 data-src 等懒加载地址及可确认的原图链接，避免透明占位图；支持 MediaWiki GIF 原图与 Fandom revision/scale 地址；Fandom 原图请求追加 format=original，避免 CDN 自动改为 WebP。原图失败时尝试缩略图并提示动画可能丢失。`srcset` 保留最高分辨率候选并有原 src 回退。`WebWikiTest` 验证超过旧 1 MB 限额的双帧 GIF 仍按原始字节保存。未勾选的媒体不离线下载；已勾选但不可获取、格式不支持或超限的媒体显示占位与警告。嵌入平台播放器、HLS/DASH、blob/DRM 流媒体、交互图表及完整网页应用目前无法离线保存。不允许 SVG、外链脚本和活动内容。媒体下载只支持 HTTP 显式代理，其它代理配置会提示资源未保存。

## 运行配置

Windows 默认查找已安装 Chrome / Edge。可在 `backend/.env` 指定：

```dotenv
MINIS_WEB_EXECUTABLE_PATH=C:/Program Files/Google/Chrome/Application/chrome.exe
MINIS_WEB_HEADLESS=true
MINIS_WEB_LOCALE=zh-CN
MINIS_WEB_TIMEZONE=Asia/Shanghai
MINIS_WEB_ALLOW_FAKE_IP=false
MINIS_WEB_PROXY_SERVER=
```

也可运行 `backend/install-browser.ps1` 安装版本匹配的 Chromium。Linux 安装命令为 `mvn exec:java -Dexec.mainClass=com.microsoft.playwright.CLI -Dexec.args="install --with-deps chromium"`。

优先使用本机 Chrome/Edge；备用 Chromium 通过 `channel=chromium` 启用完整浏览器的新版 headless。语言、时区、视口、屏幕尺寸和缩放一致配置；User-Agent 从运行中的浏览器读取版本和平台，移除 HeadlessChrome 标记。关闭自动化提示参数及 Blink 自动化标记；WebSocket 通过原生路由阻止连接，保留原生 API。Cookies 在同一隔离会话内延续，不读取个人浏览器资料或登录状态。WebRTC 与网站写入仍受限制。HTTP 403/429 与验证页面保留画面、标为阻塞且禁止提取；环境模拟不能保证消除基于 IP、行为或验证挑战的拦截。

代理使用 `198.18.0.0/15` Fake-IP DNS 时，可显式设置 `MINIS_WEB_ALLOW_FAKE_IP=true`；此开关仅允许域名解析得到的该地址段，直接输入保留 IP 仍被禁止。显式代理可通过 `MINIS_WEB_PROXY_SERVER=http://127.0.0.1:7890` 配置；没有关闭 TLS 校验。

需要处理验证时，可以设置 `MINIS_WEB_HEADLESS=false` 在后端所在桌面显示浏览器窗口，由人处理；网页内的跨源验证框当前不能通过会话预览直接操作。Google 仍可能限流或拒绝自动访问，不承诺无人值守搜索始终成功。

Docker 镜像构建时安装 Chromium 和系统依赖，以 UID 10001 的非 root 用户运行，Compose 配置 Chromium 沙箱所需的官方 seccomp profile 和 init。旧数据卷若由 root 写入，需要先备份并调整 `/data` 的访问权限；本次不会自动修改既有卷。桌面包使用系统浏览器或按安装脚本预装 Chromium。

## 验证

`WebSnapshotTest` 覆盖 HTML 净化、媒体选择与控件、证据锚点、引用校验、保留地址拒绝、版本去重、检索发布与删除清理。设置 `MINIS_BROWSER_TEST=true` 后运行 `WebBrowserTest`，使用本机 HTTP fixture 与真实无头浏览器验证语言/时区/UA、导航、隔离、正文与媒体提取、超限流式下载、私网跳转拒绝、403 阻塞和不可变证据。前端 `npm run test:web` 验证可读 URL 的访问等价性、保留分隔符和非法编码处理。

参考：[Playwright Java 线程模型](https://playwright.dev/java/docs/multithreading)、[Mozilla Readability](https://github.com/mozilla/readability)、[Playwright Docker](https://playwright.dev/java/docs/docker)、[新版 headless 与 Chrome/Edge](https://playwright.dev/java/docs/browsers#chromium-new-headless-mode)、[浏览器环境模拟](https://playwright.dev/java/docs/emulation)。Readability 源码与许可证在 `backend/src/main/resources/web/`；Docker seccomp profile 来自 Playwright v1.58.0 官方仓库。

Wiki 结构参考：[MediaWiki 页面 ID 与类](https://www.mediawiki.org/wiki/Manual:Interface/IDs_and_classes)。`SnapshotExtract.js` 在读取源码与清洗之间保留知识结构；`WebWikiTest` 覆盖 Wiki 与普通文章的信息框、Fandom 字段、隐藏立绘、GIF 原始字节及菜单排除。
