Notes设计说明 READ ME

01 / 碳黑 + 暗玻璃 + 工业黄

底色是近黑的碳黑（#07080a），面板是半透明暗玻璃 （rgba(15,18,21,.62) + backdrop-filter: blur(16px)）。 玻璃要能被"看见"，背后必须真有东西——所以底层铺了线框球体、等高线、技术网格与扫描带。 工业黄是唯一强调色，且几乎只做几何与描边，不做大段正文。

02 / 切角与角标

所有面板用对角线切角（clip-path）， 且切角方向刻意不对称；未被切的两个角打发光 L 形角标。 1px 切角描边由"外层描边环 + 内层玻璃各内缩 1px"实现。

03 / 全息叠加层

叠加板 = 等高地形线 + 网格 + 目标方框 + 十字准星 + 矢量箭头 + 高程剖面， 再压一层等距横纹（veil）与循环扫描带。 图像层同理：去色 → multiply 叠黄 → 横纹 → 目标框 + 括号。

04 / 等宽即仪表

所有读数、坐标、时间、编号一律 monospace + tabular， 并保留前导零（0000-0471）与单位小字。 它制造的是"仪表显示"而非"文案排版"的观感。

05 / 光晕替代阴影

深色档的"浮起"由 黄色光晕 （box-shadow: 0 0 14px）承担，不用模糊投影； 浅色档则换成硬偏移阴影（6px 6px 0）。 同一个 --shadow 令牌，两种语汇。

06 / 这正是"主题宿主"的实证

右上角切换 DARK·HUD ↔ LIGHT·PRINT，结构一个节点没动。 说明这套语言里真正"可投影"的部分是： 颜色 · 玻璃/模糊 · 光晕/阴影 · 网格 · 切角。 而不能投影、必须跟着风格写死的部分是： 全息叠加的图形内容、等高线形状、目标框语义、图像处理链路—— 也就是「形状层」与「图像层」。
